# Дела — записная книжка с галочками и календарём

Простой список дел на телефон и компьютер: **сегодня, неделя, месяц, долгосрочные**, разделы **работа / дом**,
невыполненное само переезжает на следующий день. Ничего не требует: ни регистрации, ни интернета после первого открытия.

**Открыть:** https://allamitsamara-cmd.github.io/dela/

## Ваши дела никуда не уходят

Всё, что вы записываете, хранится **только в вашем браузере** (localStorage) на том устройстве, где вы это ввели.
Приложение не имеет сервера, не отправляет ничего в сеть, не собирает статистику, не ставит счётчиков.
Проверить это можно по коду: в `app.js` нет ни одного запроса наружу.

Из этого же следует: телефон и компьютер — два разных списка. Чтобы перенести дела с одного на другой,
есть «Сохранить копию в файл» и «Загрузить копию из файла» в меню «⋯» (файл JSON, который вы сами передаёте как хотите).
Если стереть данные браузера, дела пропадут — делайте копию.

## Что умеет

- **Сегодня** — полоска недели с числами и точками дел. Тап по числу — этот день, стрелки листают недели.
  Дело можно записать с временем («+ время»), тогда оно встаёт в начало дня.
- **Неделя** — список «на неделю» без привязки к дню, плюс дела этой недели по дням.
- **Месяц** — календарная сетка с точками, тап по числу открывает день; ниже список «на месяц».
- **Долгосрочные** — без срока.
- Фильтр **Все / Работа / Дом**. У рабочих дел синий корешок и квадратик, у домашних — голубой и кружок.
- Галочка: сделанное уходит вниз зачёркнутым с датой.
- **Перенос**: при открытии всё невыполненное за прошлые дни переезжает на сегодня (за прошлую неделю — на эту,
  за прошлый месяц — на этот) с красной меткой «перенесено ×N», чтобы было видно, что дело кочует.
- Меню «⋯» на деле: перенести на завтра, на следующую неделю или месяц, выбрать дату, указать время,
  сменить раздел, изменить текст, удалить.
- Тёмная тема — если она включена в системе.

## Поставить на телефон

1. Откройте https://allamitsamara-cmd.github.io/dela/ в браузере телефона (Chrome на Android, Safari на iPhone).
2. Android: меню браузера → **«Добавить на главный экран»** (или «Установить приложение»).
   iPhone: кнопка «Поделиться» → **«На экран „Домой“»**.
3. Значок «Дела» появится рядом с другими приложениями и будет работать без интернета.

## Поставить на компьютер

Можно просто открыть ту же ссылку в браузере и добавить в закладки.

Если хочется запускать значком с рабочего стола и без интернета вообще, скачайте репозиторий
(зелёная кнопка **Code → Download ZIP**), распакуйте в любую папку и запустите `Дела.pyw`
(нужен установленный [Python](https://www.python.org/downloads/) 3.10 или новее). Он поднимает крошечный сервер
только на вашем компьютере (`127.0.0.1:8124`) и открывает браузер; окон не показывает.
Ярлык на рабочий стол: правой кнопкой по `Дела.pyw` → «Создать ярлык», у ярлыка в свойствах — «Сменить значок…» → `icons/dela.ico`.

## Свой экземпляр на GitHub Pages

Форкните репозиторий, в настройках форка включите **Pages** (Source: branch `main`, folder `/`) —
через минуту приложение откроется по адресу `https://<ваш-логин>.github.io/dela/`. Никаких сборок и зависимостей.

## Устройство

Один `index.html` (разметка и стили), `app.js` (вся логика, без библиотек), `sw.js` (оффлайн-кэш), `manifest.webmanifest` и иконки.
Задача — объект `{text, area, bucket, key, time, done, carried, …}`, где `bucket` — день / неделя / месяц / долгосрочное,
а `key` — дата, понедельник недели или месяц. Хранилище — ключ `dela.v1` в localStorage.
